# Knowledge Garden Publisher

Knowledge Garden Publisher 是知识花园的桌面编辑与发布工具。它可以管理多个本地博客、编辑 Markdown 笔记、切换公开/私密状态，并在发布前检查变更。

## 使用图片库

1. 打开一篇笔记，在编辑器工具栏点击“图片库”。首次打开时，应用会自动为当前笔记创建专属图片文件夹。
2. 点击“添加图片”，在系统文件选择器中一次选择一张或多张图片。
3. 在“确认添加图片”界面检查缩略图。点击某张图片旁的“移除”只会把它从本次候选列表移除，不会删除原文件。
4. 如果图片与库中已有文件同名，应用会显示冲突，并要求再次确认后才会覆盖。
5. 点击图片缩略图可查看完整预览、文件名、像素尺寸和文件大小。
6. 点击“复制 Markdown 链接”会把该图片的相对链接复制到剪贴板；应用不会自动修改 Markdown 笔记，请在需要的位置自行粘贴。
7. 点击“删除图片”后仍需再次确认。确认后是永久删除，无法恢复。

## 文件位置

图片库按笔记文件名隔离存放：

- 公开笔记：`content/_assets/<note-slug>/`
- 私密笔记：`private/_assets/<note-slug>/`

空图片库会保留一个 `.gitkeep`，让 Git 能够记录该文件夹；加入第一张图片后占位文件会移除，删除最后一张图片后会自动恢复。

当前版本不支持在应用内重命名笔记路径。若以后修改路径，需要同步迁移对应的图片文件夹和 Markdown 链接。

### 本地 master 与 GitHub main 不一致

如果本地博客仍使用 `master`，但它明确跟踪 `origin/main`，发布窗口会说明原因并提供“安全切换到 main 并继续”。软件只重命名本地分支并保留 `origin/main` 上游、当前提交和未提交文件。若本地已存在 `main`、上游不同、有暂存内容或 Git 操作正在进行，软件会拒绝自动修改并显示原因。

## 支持范围与限制

- 格式：PNG、JPG、JPEG、GIF、WebP、AVIF。
- 单张图片最大 25 MiB。
- 每次最多选择 50 张图片。
- 应用会在解码前检查图片结构、文件大小和安全的像素尺寸预算；超过限制或格式与扩展名不匹配的文件不会导入。
- 复制链接不会自动修改 Markdown；覆盖和永久删除都会要求明确确认。
