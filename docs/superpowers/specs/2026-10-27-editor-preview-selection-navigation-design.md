# 编辑器选中文本定位预览设计

## 目标

在 Knowledge Garden Publisher 的 Markdown 编辑器工具栏中增加“定位预览”按钮。用户在左侧编辑器选中文字后点击按钮，右侧自动切换到“当前笔记”，滚动到对应的渲染内容并短暂高亮。该操作只用于导航，不修改 Markdown、不保存文件，也不触发发布。

## 用户交互

1. 用户在左侧 Markdown 编辑器中选中一段文字。
2. 用户点击工具栏中的“定位预览”。
3. 应用切换右侧预览标签到“当前笔记”。
4. 应用在当前笔记预览中查找对应文本。
5. 匹配成功时，将对应内容平滑滚动到预览区域中央，并高亮约两秒。
6. 没有非空选择时，编辑器附近显示“请先选择要定位的文字”。
7. 匹配失败时显示“预览中未找到对应内容”，并保持预览原有滚动位置。

按钮在存在当前笔记时显示。博客切换期间编辑器只读，按钮随编辑器操作一起禁用。

## 组件边界

### MarkdownEditor

- 从 CodeMirror 主选区读取起止偏移和原始选中文本。
- 折叠选择或仅包含空白的选择不发出定位请求。
- 通过回调向父组件发送不可变的定位请求：选中文本、选择中点相对全文的比例，以及单调递增的请求编号。
- 显示由父组件返回的成功或失败状态，不直接访问预览 DOM。

### App

- 连接编辑器和预览区。
- 保存最近一次定位请求和结果提示。
- 切换笔记或博客时清除过期请求，避免旧请求作用于新文档。

### PreviewPane

- 收到新请求后切换到“当前笔记”标签。
- 等待目标预览 DOM 就绪，然后执行匹配。
- Quartz 精确预览保持跨源隔离，由受信任主进程仅在匹配的本机回环地址子 frame 中执行定位；简化预览在本地文章节点中定位。
- 向父组件报告成功、未找到或预览不可访问。

## 文本匹配

匹配只检查正文可见文本，排除脚本、样式、导航、目录和其他非正文区域。

1. 将选中文字和候选文本统一换行、合并连续空白并去除首尾空白。
2. 先尝试完整连续文本匹配。
3. 如果选区包含常见 Markdown 装饰符，额外尝试去除标题符号、强调符号、链接语法和行内代码定界符后的文本。
4. 多个候选同时匹配时，按候选在预览正文中的相对位置与编辑器选择位置比例的距离排序，选择最接近的一项。
5. 不进行模糊拼写匹配，避免跳到错误段落。

定位目标优先选择包含匹配文本的最近块级元素，如标题、段落、列表项、引用或代码块；找不到块级祖先时使用文本节点父元素。

## 滚动与高亮

- 使用 `scrollIntoView({ block: "center", behavior: "smooth" })`。
- 为命中元素添加发布器专用高亮类，约两秒后移除。
- 新请求到达时立即移除上一次高亮并取消旧的清理计时器。
- 组件卸载、切换标签或切换笔记时清理高亮和计时器。
- 高亮样式仅注入当前本地预览，不写入 Quartz 源文件，也不影响线上站点。

## 失败与边界处理

- 无选择或纯空白选择：不切换标签，不滚动。
- 预览正在重建：等待当前可用预览；若没有可访问内容则返回“当前预览尚未就绪”。
- iframe 尚未加载：在加载完成后处理仍然有效的最新请求。
- 子 frame 尚未注册或已经跳转：显示“当前预览尚未就绪”，不放宽 iframe 沙箱，也不读取线上公开站。
- 选区过长时限制传入匹配器的文本长度，避免阻塞界面；仍保留足够的开头和结尾文字用于准确匹配。
- 重复点击只处理最新请求，旧请求不得覆盖新结果。

## 安全与兼容性

- 不向预览页面执行任意脚本，不使用 `eval`。
- 不修改 iframe 的沙箱权限。
- 不读取线上公开站的 DOM；定位只作用于“当前笔记”的本地预览。
- 不改变现有自动保存、恢复稿、图片库和发布逻辑。
- 兼容公开和私密笔记，以及 Quartz 不可用时的简化预览。

## 测试

### 单元测试

- MarkdownEditor：无选择提示；有效选择发出正确文本和位置比例；只读时按钮禁用。
- 文本匹配器：空白归一化、Markdown 装饰清理、重复文本按位置消歧、找不到时无结果。
- PreviewPane：自动切换“当前笔记”；精确预览和简化预览都能滚动并高亮；失败时不改变滚动位置；后到请求淘汰旧请求。

### 集成与回归测试

- App 正确连接编辑器请求和预览结果提示。
- 切换笔记后旧请求不会定位新笔记。
- 现有保存、搜索、图片库、私密预览和预览标签测试保持通过。

### 手动验证

- 在长笔记中分别选择标题、普通段落、列表项、代码和重复文字验证定位。
- 在公开笔记、私密笔记及简化预览中验证滚动和高亮。
- 验证按钮操作不会产生文件变化或可发布变化。
