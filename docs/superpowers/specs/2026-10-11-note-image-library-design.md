# 笔记图片库设计

## 目标

为 Knowledge Garden Publisher 的每篇笔记提供独立图片库。用户可以从编辑器工具栏打开图片库，浏览、添加、预览、复制 Markdown 链接及永久删除图片。图片库只管理附件，不自动修改 Markdown 内容。

## 用户体验

### 打开图片库

- Markdown 编辑器工具栏新增“图片库”按钮。
- 仅在已打开笔记时启用按钮。
- 点击后检查并创建当前笔记专属目录：
  - 公开笔记：`content/_assets/<note-slug>/`
  - 私密笔记：`private/_assets/<note-slug>/`
- 图片库以居中弹窗呈现，标题显示当前笔记名称。
- 图片按文件名自然排序，以缩略图网格显示。
- 空图片库显示“暂无图片”和“添加图片”入口。

### 添加图片

- “添加图片”打开系统文件选择器，支持一次选择一张或多张图片。
- 支持 PNG、JPG/JPEG、GIF、WebP 和 AVIF。
- 一次最多选择 50 张，每张最大 25 MB。
- 选择后先显示缩略图确认界面，用户可以移除误选图片或取消整个操作。
- 确认前完成类型、大小、文件身份、目标路径及同名冲突检查。
- 如存在同名图片，列出全部冲突；用户只能选择“覆盖并继续”或返回修改选择。
- 写入采用批次事务：任何图片写入失败时，删除本批新增文件并恢复本批被覆盖的旧文件。
- 添加完成后立即刷新图片网格。

### 查看与复制链接

- 点击缩略图打开大图预览。
- 预览显示文件名、像素尺寸和文件大小。
- “复制 Markdown 链接”只向系统剪贴板写入下列格式，不修改笔记：

  ```markdown
  ![文件名](<../_assets/<note-slug>/文件名.png>)
  ```

- 替代文字使用不含扩展名的文件名；目标始终使用尖括号形式，以正确支持空格和 Unicode 文件名。

### 删除图片

- 大图预览提供“删除图片”。
- 删除前显示文件名以及“永久删除、无法恢复”的二次确认。
- 删除时重新验证目标仍是图片库内原先查看的普通文件。目标被外部替换或变化时拒绝删除。
- 删除成功后关闭大图预览并刷新图片网格。

### Markdown 与博客预览

- 创建图片库、添加图片、复制链接和删除图片均不得修改 Markdown 文件。
- 图片操作不得改变编辑器的脏状态或触发笔记保存。
- 只有用户自行把复制的链接粘贴进 Markdown 后，右侧博客预览才显示该图片。

## 空目录的 Git 表示

Git 不保存空目录，因此空图片库包含隐藏占位文件 `.gitkeep`。

- 图片列表忽略 `.gitkeep`。
- 添加第一张图片后移除 `.gitkeep`。
- 删除最后一张图片后重新创建 `.gitkeep`。
- 占位文件允许空图片库随正常发布流程进入 GitHub。

## 架构

### 渲染进程

新增独立 `ImageLibrary` 组件，负责：

- 图片库、选择确认、冲突确认、全图预览和永久删除确认等界面状态；
- 通过受限的 preload API 请求图片数据和操作；
- 将返回的 Markdown 链接写入系统剪贴板；
- 不接触绝对磁盘路径，不直接读写文件。

缩略图在列表请求中返回有限尺寸的数据；全图数据仅在用户打开单张预览时按需请求。关闭弹窗或切换笔记时丢弃旧请求结果，防止跨笔记显示。

### 主进程服务

新增聚焦的图片库服务，输入只接受当前笔记的受管相对路径和图片库内的相对文件名。服务负责：

- 解析并验证笔记所属的公开或私密根目录及英文 slug；
- 确保图片库目录存在并维护 `.gitkeep`；
- 列举经过验证的图片并生成受限缩略图；
- 使用 Electron 系统对话框选择源文件，但不向渲染进程暴露源绝对路径；
- 使用短期、不透明选择标识保存待确认批次，确认时重新验证源文件身份；
- 检测同名冲突并执行可回滚的批量复制；
- 按需读取单张全图预览；
- 对永久删除执行身份复核；
- 生成规范的 Markdown 相对链接。

选择标识绑定当前工作区和笔记，并设置短期有效期；博客切换、笔记切换确认或应用关闭后不得复用。

### IPC 与契约

为图片库定义独立、严格校验的请求和响应：

- 打开或刷新图片库；
- 选择图片并返回待确认缩略图；
- 确认添加，可显式允许覆盖已报告的冲突；
- 加载单张大图预览；
- 永久删除单张图片；
- 复制文本到剪贴板。

所有返回值继续使用现有 `IpcResult` 错误模型；错误信息对用户使用中文，内部绝对路径不返回界面。

## 安全与一致性

- 仅允许上述五类图片扩展名，并通过文件内容签名验证实际格式；扩展名和内容不一致时拒绝。
- 源文件和目标均必须是普通文件；拒绝符号链接、junction 和其他特殊文件。
- 所有目标路径必须保持在当前笔记的 `_assets/<note-slug>/` 内。
- 文件名清除控制字符及 Windows 非法字符；禁止保留名、尾部空格和尾部点。
- 批量添加在专用暂存目录完成，覆盖前保存旧版本；全部目标发布成功后才清理暂存数据。
- 对最终发布边界和删除边界做身份复核；外部并发变化导致操作失败而不是覆盖未知内容。
- 图片库操作与现有笔记改名、公开/私密切换、删除和发布附件机制保持兼容。
- 缩略图尺寸和编码结果设上限；完整预览一次只加载一张，释放旧数据后再加载下一张。

## 错误处理

- 用户取消文件选择或确认弹窗视为正常取消，不显示错误。
- 输入不受支持、过大、已变化或不安全时，指出对应文件名和原因。
- 同名冲突必须由用户显式批准覆盖；批准只对本次已列出的冲突生效。
- 批量复制失败时回滚本批变化，并报告未完成；若回滚无法确认，显示需要人工检查的错误，不宣称成功。
- 图片库目录无法创建、缩略图无法生成、预览读取失败及永久删除失败均保留原有文件，并允许重试刷新。

## 验收与测试

### 服务与 IPC

- 公开、私密以及自定义领域笔记均解析到正确的专属目录。
- 首次打开创建空目录和 `.gitkeep`；第一张图片加入后删除占位；最后一张删除后恢复占位。
- 单图、多图、自然排序、支持格式及大小和数量边界正确。
- 拦截错误签名、符号链接、路径穿越、保留文件名和外部并发替换。
- 同名冲突在未批准时不写入，批准后覆盖；任一复制失败会恢复整个批次。
- 删除必须经过确认并只删除经身份复核的目标。
- 所有 IPC 请求与响应经过 schema 校验，未授权 renderer 被拒绝。

### 渲染界面

- 按钮启用状态、空态、缩略图网格、选择确认和冲突确认正确。
- 大图预览显示文件名、尺寸和大小。
- 复制按钮写入精确 Markdown 链接并显示成功反馈。
- 永久删除确认可取消，成功后列表刷新。
- 快速切换笔记或关闭弹窗时不显示迟到的旧请求。
- 所有图片库操作前后，当前 Markdown 内容、修订哈希及编辑器保存状态保持不变。

### 集成与打包

- 现有完整单元和集成测试继续通过。
- Electron 端到端测试覆盖创建空库、添加、查看、复制和删除的主流程。
- Windows 安装包构建成功，并对安装版执行启动及图片库基本冒烟测试。

## 非目标

- 不自动插入或修改 Markdown。
- 不支持拖放、粘贴图片、文件夹批量导入、图片编辑、压缩、裁剪、重命名、搜索或跨笔记共享。
- 不在本期支持 SVG、PDF、视频或其他附件格式。
